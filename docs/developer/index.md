# For Developers

!!! danger "This section is for the app maintainer — not for normal use"
    Everything under **For Developers** documents the app's internal code, its CLASP sync, Script IDs, and developer-only menu tools. **You never need anything here to run your budget or to complete End of Year.**

    If you are here to *use* the budget, go to the [End of Year Overview](../guides/yearly-tasks/end-of-year/overview.md) or [Setup](../guides/yearly-tasks/end-of-year/setup.md) guides instead. Acting on the instructions in this section without understanding the code can damage the live spreadsheet.

## What's in here

- **[EOY Developer Guide](developer-guide.md)** — internals of the End of Year process: architecture, state machine, distribution logic, the annual CLASP re-point and project rename, and known technical limitations.
- **[Developer Menu Reference](developer-menu.md)** — every tool on the in-app Developer menu (visible only when Developer Mode is on).

These pages are for whoever maintains the software after each budget year. Everything a household needs for day-to-day budgeting lives under **Guides**.
